# Konteks Proyek

Platform riset dwibahasa: manajemen proyek, pembuat kuesioner (Likert fleksibel), persetujuan, pengumpulan respons, data, analisis statistik, integrasi Google Sheets, ekspor. Pengguna: peneliti (dashboard privat) dan responden (tanpa akun, via URL publik). Pendaftaran peneliti kelak berbasis undangan (tidak ada registrasi publik).
Arah desain: SaaS minimalis, putih hangat, hijau sage (primer), biru lembut (sekunder), arang, font Inter.
Rencana masa depan (BUKAN sekarang): Supabase, auth, versi kuesioner, ekspor, Google Sheets, mesin R.
